## 下一步：第 2 步 选定引擎与联网方案

- **要做的事**：比较候选引擎对微信小游戏导出、触屏输入和实时联网的支持；在真机上测试 WebSocket 与 UDP 的可用性。
- **完成条件**：
  - 选择与理由写入项目文档（计划为 `docs/ARCHITECTURE.md`）；
  - 用所选引擎建的空项目能在微信开发者工具与真机运行。
- **由谁决定**：引擎与联网方案由用户选定；助手可整理候选对比和真机测试方法，不代为选定。
- **已知背景**：
  - 入门想法中倾向的 Godot 是为横版单机提出的，是否适合本作待核对。
  - 微信文档显示 UDP 接口自基础库 2.7.0 起提供（小程序文档，小游戏适用情况待核对）；开发者社区有不能广播、跨网段受限等反馈，多为 2019—2022 年内容，选型时需按时效重新核对。
  - 交接中还列有“进入项目前核对微信小游戏的包体、性能、实时联网与商业化规则”，可在本步一并核对。
  - 助手建议（尚未确认）：开工前先选定联网方案，代码按“输入→状态”组织。
